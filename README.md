# Lista de Pokémon

## Autora
**Thaís Vitória Dias Rosa**

## Sobre o Projeto

Este projeto foi desenvolvido em **React Native** utilizando **Expo**, com o objetivo de praticar o consumo de APIs através de requisições HTTP utilizando o método **fetch**.
A aplicação permite que o usuário pesquise Pokémon pelo nome e visualize suas informações em uma lista utilizando o componente **FlatList**. Os dados são obtidos diretamente da **PokéAPI**, uma API pública e gratuita voltada para informações do universo Pokémon.

---

## Funcionalidades

- Buscar Pokémon pelo nome.
- Realizar requisições HTTP utilizando **fetch**.
- Exibir nome, altura e peso.
- Utilizar **FlatList** para listar os Pokémon pesquisados.
---

## Tecnologias Utilizadas

- React Native
- Expo

---

## Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/ThaisVDR/Lista_Pokemon.git
```

2. Acesse a pasta do projeto:

```bash
cd Lista_Pokemon
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm start
```

5. Abra no Expo Go ou em um emulador.

Desenvolver uma aplicação que realize requisições HTTP utilizando **fetch**, consumindo uma API pública e exibindo os resultados através do componente **FlatList**, aplicando conceitos fundamentais de React Native.
